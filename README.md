# Sui Move Labs

A collection of Sui Move smart contracts, learning exercises, experiments, and projects built while exploring the Sui blockchain ecosystem.

## About

This repository serves as my personal workspace for learning and building with Sui Move. It contains practice projects, smart contracts, and experiments that help me deepen my understanding of blockchain development on the Sui network.

## Getting Started

### Clone the Repository

```bash
git clone https://github.com/Adamsonoladipupo/building_on_sui.git
cd building_on_sui
```

### Build a Project

```bash
move build
```

### Run Tests

```bash
move test
```
